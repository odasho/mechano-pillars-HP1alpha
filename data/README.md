# Data

This folder contains the metadata JSON of every nucleus (`*_hela_experiments_meta/`), in the
folder structure of the image data. Paths in the JSON files are relative to this folder.

Download the image data from the data deposit (DOI: <!-- TODO: add DOI -->) into this
folder, so that the session folders (`*_data_files/`, `*_Ilastik_segmentation_2/`,
`*_annotation_files_nucleus/`, ...) sit next to their `*_hela_experiments_meta/` folder.
See "Data structure" in the main README for the full layout.
